# Траектория обучения Claude Code (Learning Path)

**Освойте Claude Code за 8–11 часов. Углубляйтесь в интересующие темы по мере необходимости.**

Это ваша структурированная отправная точка. Проходите модули по порядку, а затем обращайтесь к полному руководству за деталями.

## Как проходить этот курс

### Шаг 1: Оцените свой уровень

**Новичок** (первый день в Claude Code):
- Экспресс-маршрут: 01 → 02 → 03 (около 2 часов)
- Затем переходите к части `Part 1: Quick Start` в полном руководстве

**Средний уровень** (работаете с Claude Code от 1 до 4 недель):
- Полный маршрут: 01 → 07 (8–11 часов)
- Основное внимание уделите модулям 04, 05, 06, 07

**Опытный пользователь** (более 1 месяца практики):
- Бегло просмотрите 01–03, подробно изучите 04–07
- Переходите к главе 9 полного руководства (Advanced Patterns) для сложной оркестрации

### Шаг 2: Выберите трек

**Трек A: Освоение фундамента** (11 часов)
- Последовательно пройдите модули 01–07
- Выполните все практические задания
- Проверяйте знания через `/lesson-quiz [topic]` после каждого модуля
- Завершите самооценку командой `/self-assessment comprehensive`

**Трек B: Фокус на практических навыках** (4–6 часов)
- Модули 01–02 (база)
- Переход к модулю 04, 05 или 06 в зависимости от вашей цели
- Глубокое погружение в выбранный модуль

**Трек C: Внедрение в команду** (5–7 часов)
- Модули 01–02 (обучение фундаментальным принципам)
- Модуль 03 (настройка командной конфигурации)
- Модули 04–07 (командные рабочие процессы)

### Шаг 3: Обучение и валидация

Каждый модуль включает в себя:
- 📖 **Теория** (10–30 мин): ключевые концепции и ментальные модели
- 🔨 **Практика** (20–45 мин): реальные примеры из папки `examples/`
- 📝 **Проверка понимания**: квиз по теме

## Краткий обзор модулей

### Модуль 01: Установка и настройка (15 мин)
**Цель:** запустить Claude Code и подтвердить работоспособность
- Установка на вашу ОС (macOS / Linux / Windows)
- Выполнение первой команды
- Понимание цикла "промпт → ответ"
- **Упражнение:** воркфлоу «Первые 5 минут»

### Модуль 02: Базовый цикл (45 мин)
**Цель:** понять архитектуру работы инструмента
- Цикл взаимодействия (промпт → инструмент → решение → обратная связь)
- Контекст и сессии
- Режим планирования Plan Mode, уровни усилий (effort)
- **Упражнение:** планирование реальной задачи через `/plan`

### Модуль 03: Память и конфигурация (1 час)
**Цель:** адаптировать Claude Code под свой проект и команду
- Структура и иерархия файлов `CLAUDE.md`
- Приоритеты настроек
- Переменные окружения
- **Упражнение:** создание первого `CLAUDE.md`

### Модуль 04: Агенты и специализация (1.5 часа)
**Цель:** создание узкоспециализированных агентов
- Когда нужен агент вместо единой сессии
- Ограничение инструментов и изоляция
- Описание агентов в `.claude/agents/<name>.md`
- **Упражнение:** создание и тест двух агентов (универсала и эксперта)

### Модуль 05: Навыки (Skills) и автоматизация (1.5 часа)
**Цель:** создание переиспользуемых модулей знаний
- Жизненный цикл навыков и YAML-фронтматтер
- Автовызов по описанию и явный вызов
- Подключение скриптов к навыкам
- **Упражнение:** создание навыка для регулярной задачи

### Модуль 06: Хуки и события (1 час)
**Цель:** автоматизация реакции на системные события
- События жизненного цикла и матчеры
- Валидация перед запуском (`PreToolUse`) против пост-обработки
- Безопасное написание скриптов
- **Упражнение:** создание защитного хука валидации

### Модуль 07: Продвинутые паттерны (2–3 часа)
**Цель:** оркестрация многоагентных процессов
- Команды агентов и зависимости
- Паттерны оркестрации
- Обработка сбоев и восстановление
- **Упражнение:** проектирование рабочего процесса из 3 агентов

# Модуль 01: Установка и настройка (Installation & Setup)

**Время**: 15 минут | **Сложность**: ⭐ Начинающий

## Цель

Установить и запустить Claude Code в вашей системе. Убедиться в корректности работы, выполнив первую команду.

---

## Что вы узнаете

- Как установить Claude Code на вашу ОС (macOS / Linux / Windows)
- Как устроен базовый цикл «промпт → ответ»
- Как выполнить первую команду
- Как вызывать справочную систему

---

## Установка

### macOS, Linux, WSL (нативный установщик, рекомендуется)

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Откройте новое окно терминала и проверьте версию:
```bash
claude --version
```

Нативный установщик обновляется автоматически в фоновом режиме.

### macOS (Homebrew)

```bash
brew install --cask claude-code
```

*Версии через Homebrew не обновляются автоматически. Периодически выполняйте `brew upgrade claude-code`.*

### Windows

В PowerShell:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Или через WinGet:

```powershell
winget install Anthropic.ClaudeCode
```

*На нативной Windows рекомендуется установить [Git for Windows](https://git-scm.com/downloads/win), чтобы Claude Code мог использовать инструмент Bash. Пользователям WSL это не требуется.*

Для Debian, Fedora, RHEL и Alpine доступны также пакеты apt, dnf и apk. См. [официальную страницу установки](https://code.claude.com/docs/en/setup).

## Первый запуск

Перейдите в каталог любого проекта и запустите Claude:

```bash
cd ~/my-project
claude
```

При первом запуске Claude Code предложит войти в учетную запись (sign in). После этого откроется интерактивная сессия в терминале: экран приветствия с номером версии, активной моделью и рабочей директорией, а затем строка ввода промпта.

---

## Основные команды

| Команда | Назначение |
|---------|------------|
| `/help` | Показать все доступные команды |
| `/context` | Наглядное отображение расхода контекста |
| `/clear` | Начать новый диалог с пустым контекстом |
| `/resume` | Возобновить предыдущий диалог |
| `Ctrl+C` | Прервать текущую операцию |
| `/exit` | Выйти из Claude Code |

## Ваши первые 5 минут

### Упражнение 1: Просмотр доступных команд
```bash
/help
```

Обратите внимание на категории:
- **Воркфлоу**: `/plan`, `/rewind`, `/effort`
- **Сессии**: `/resume`, `/clear`, `/compact`
- **Память**: `/memory`, `/init`
- **Продвинутые**: `/model`, `/permissions`

### Упражнение 2: Проверка контекста
```bash
/context
```

Отобразится цветовая сетка заполненности контекстного окна и рекомендации по оптимизации.

### Упражнение 3: Задайте вопрос Claude
```
What files are in my project?
```
*(Какие файлы находятся в моем проекте?)*

Claude прочитает структуру файлов и ответит. Это и есть базовый цикл:

```
Ваш промпт → Claude читает файлы → Claude предлагает изменения → Вы проверяете diff → Применение
```

### Упражнение 4: Проверка предложенных изменений (Diff)

Когда Claude предлагает изменить код:
1. Показывается описание изменений
2. Выводится режим `diff` (что добавляется / удаляется)
3. Появляется запрос на подтверждение или отклонение

> **Золотое правило**: Всегда просматривайте diff перед подтверждением правок.

## Ключевые понятия

### Сессии (Sessions)
Каждый запуск `claude` создает новую сессию, сохраняемую локально.
- Продолжить последнюю сессию: `claude --continue`
- Выбрать из списка прошлых сессий: `claude --resume` или команда `/resume`
- Сессия привязана к контексту конкретного проекта.

### Контекст (Context)
Контекст — это объем информации, который модель удерживает в памяти одновременно.
- Много свободного места: работайте спокойно.
- Заполнение более 70%: выполните `/compact`.
- Переход к принципиально новой задаче: выполните `/clear`, чтобы не тянуть старый контекст.

### Интеграция с Git
Claude Code считывает текущую ветку, статус непринятых изменений и запрашивает одобрение перед выполнением коммитов или команд терминала.

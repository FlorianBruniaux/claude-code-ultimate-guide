## Что такое агенты (субагенты)?

**Агент** (в терминологии Claude Code — **субагент**) — это специализированный ассистент с собственным системным промптом и **изолированным контекстным окном**, настроенный на решение одной задачи. Основная сессия делегирует ему работу и получает готовый результат, не засоряя общий контекст деталями поиска.

### Сравнение: Claude в общей сессии vs Агент

| Параметр | Обычный Claude | Специализированный агент |
|----------|----------------|--------------------------|
| Область задач | Универсальная | Строго сфокусированная |
| Контекст | Единый общий диалог | Собственное изолированное контекстное окно |
| Инструменты | Доступны все разрешенные | Ограниченный набор (Read-only, без сети и т.д.) |
| Скорость | Переключается между контекстами | Фокус на одном типе операций |
| Применение | Исследование, архитектура | Повторяющиеся рутинные процессы |

> В Claude Code нет слэш-команды `/agent`. Субагент вызывается тремя путями: явным упоминанием по имени в тексте промпта, через `@`-меню (`@"code-reviewer (agent)"`) или запуском всей сессии в роли этого агента: `claude --agent code-reviewer`.

## Создание первого агента

Субагент описывается одним Markdown-файлом в `.claude/agents/` (на уровне проекта) или в `~/.claude/agents/` (глобально для всех ваших проектов).

### Базовая структура файла

YAML-фронтматтер в начале файла задает конфигурацию, а тело Markdown становится системным промптом:

```markdown
---
name: code-reviewer
description: Проверяет код на баги, производительность и уязвимости. Используй после изменения кода.
tools: Read, Grep, Glob, Bash
model: sonnet
---

Вы выступаете в роли эксперта по код-ревью.

## Назначение
Проводить глубокий анализ кода на:
- Логические ошибки и краевые случаи (null-pointer, off-by-one)
- Узкие места производительности (O(n²), избыточные рендеры)
- Риски безопасности (инъекции, утечки секретов)
- Чистоту стиля и покрытие тестами

## Порядок действий
1. Выполните `git diff` для просмотра последних правок
2. Проверьте обработку ошибок
3. Сформулируйте четкий список замечаний с указанием строк
```

Поле **`description`** критически важно — именно на его основе Claude решает, стоит ли делегировать задачу данному агенту.

## Ограничение инструментов (Tools & Safety)

По умолчанию субагент наследует все инструменты основной сессии. Для безопасности доступ можно сузить:

```yaml
# Агент-аналитик только для чтения (не может менять файлы или запускать опасные команды):
tools: Read, Grep, Glob

# Агент рефакторинга (может редактировать код, но отрезан от внешних веб-запросов):
tools: Read, Grep, Glob, Edit, Write, Bash
disallowedTools: WebFetch, WebSearch
```

> **Важно помнить:**
> - Если вы предоставили доступ к `Bash`, агент может выполнять системные команды через командную строку. Инструмент `tools` управляет вызовами инструментов, а не отдельными bash-утилитами.
> - Чтобы заблокировать конкретную команду (например, `git push`), используйте правила в `settings.json` (`permissions.deny: ["Bash(git push *)"]`) или защитный хук `PreToolUse`.

## Практический пример: Агент `test-writer`

Создайте файл `.claude/agents/test-writer.md`:

```markdown
---
name: test-writer
description: Создает модульные и интеграционные тесты. Используй при запросе на написание тестов.
tools: Read, Grep, Glob, Edit, Write, Bash
---

# Агент генерации тестов (Test Writer)

## Назначение
Создавать надежные тесты по паттерну Arrange-Act-Assert:
- Проверять основные сценарии (happy path)
- Проверять пограничные условия и ошибки
- Запускать созданные тесты через Bash и проверять, что они проходят

## Правила
- Размещай тесты рядом с исходным кодом: `[name].test.ts`
- Не изменяй бизнес-логику самого модуля без согласования
```

Вызов агента в диалоге:
```text
@"test-writer (agent)" напиши тесты для src/utils/formatDate.ts
```

---

## Когда использовать агентов

✅ **Используйте агентов, если:**
- Задача повторяется регулярно (код-ревью, генерация тестов, аудит зависимостей)
- Требуется строгая изоляция инструментов (например, только чтение без права записи)
- Нужно сохранить основной контекст сессии чистым

❌ **Используйте обычный диалог Claude, если:**
- Вы исследуете неизвестную проблему в режиме свободного обсуждения
- Задача разовая и уникальная
- Требуется постоянный диалог с пользователем

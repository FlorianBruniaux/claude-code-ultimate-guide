# Computer Use в Claude Code

Функция **Computer Use** позволяет Claude Code управлять одобренными приложениями macOS и анализировать видимое содержимое экрана из интерактивной сессии CLI. Находится в статусе *Research Preview* для пользователей тарифов Pro, Max и Ultra. Недоступна на тарифах Team и Enterprise, в режиме `claude -p`, а также в консоли Linux и Windows.

Используйте Computer Use для нативных десктопных приложений, симуляторов мобильных устройств или инструментов с исключительно графическим интерфейсом. Для браузерных задач предпочтителен [Claude in Chrome](https://code.claude.com/docs/en/chrome); для сервисов с API — MCP-серверы. Официальный порядок приоритета инструментов: **MCP → Bash → Chrome → Computer Use**.

---

## Включение встроенного сервера

Computer Use представляет собой встроенный MCP-сервер с именем `computer-use`, отключенный по умолчанию:

1. Запустите интерактивную сессию Claude Code и вызовите команду `/mcp`.
2. Выберите пункт `computer-use` и нажмите **Enable**. Настройка сохранится для текущего проекта.
3. При запросе macOS выдайте разрешения:
   - **Универсальный доступ (Accessibility)** — для кликов, ввода текста и прокрутки.
   - **Запись экрана (Screen Recording)** — для создания скриншотов. После выдачи может потребоваться перезапуск терминала.

## Что Claude может контролировать

При первом запросе к приложению появляется диалог подтверждения:

| Категория приложения | Уровень контроля | Предупреждение |
|---|---|---|
| Браузеры и торговые платформы | Только просмотр | Видимые данные экрана отправляются в модель через скриншоты. |
| Терминалы и IDE | Только клики | Приложение эквивалентно прямому доступу к командной строке. |
| Finder | Полный контроль | Может читать и записывать любые файлы пользователя. |
| Системные настройки | Полный контроль | Может изменять системные конфигурации macOS. |
| Прочие одобренные приложения | Полный контроль | Убедитесь, что задача находится в безопасных границах. |

Во время управления экраном Claude временно скрывает посторонние окна, а после хода восстанавливает их. Терминал исключается из захвата скриншотов. На машине может работать только одна активная сессия Computer Use одновременно (действует блокировка уровня системы).

## Безопасность и конфиденциальность

- Computer Use работает на реальном рабочем столе, а не в изолированной песочнице.
- Закрывайте конфиденциальные вкладки и приложения перед включением режима.
- Нажатие клавиши **`Esc`** в любой момент мгновенно прерывает действие Computer Use. Сочетание **`Ctrl+C`** в терминале также останавливает выполнение.
- Скриншот подтверждает только графическое состояние экрана, но не гарантирует завершение фоновых транзакций или коммитов.

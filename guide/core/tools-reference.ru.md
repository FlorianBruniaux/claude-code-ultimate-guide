# Справочник встроенных инструментов Claude Code

Claude Code поставляется с набором встроенных инструментов (tools), используемых для исследования кодовой базы, изменения файлов и выполнения команд. Их не нужно устанавливать — они встроены в ядро среды.

Имена инструментов чувствительны к регистру и используются в правилах разрешений (`allow`/`deny`), фронтматтере субагентов (`tools`, `disallowedTools`), матчерах хуков и флагах CLI `--allowedTools`/`--disallowedTools`. Кастомные инструменты подключаются через [MCP-серверы](../ecosystem/mcp-servers-ecosystem.md).

## Полный список встроенных инструментов

### Работа с файлами (File Operations)

| Инструмент | Описание | Требует подтверждения |
|------------|----------|:---------------------:|
| `Read` | Чтение файлов (текст, изображения, PDF, Jupyter ноутбуки) | Нет |
| `Write` | Создание или полная перезапись файла (требует предварительного чтения, если файл существует) | Да |
| `Edit` | Точечная замена строк в существующем файле | Да |
| `NotebookEdit` | Редактирование ячеек Jupyter-ноутбука по `cell_id` | Да |
| `Glob` | Быстрый поиск файлов по маске (`**/*.ts`, `src/**`) | Нет |
| `Grep` | Поиск по содержимому файлов через регулярные выражения ripgrep | Нет |
| `LSP` | Языковой сервер: переход к определению, поиск ссылок, ошибки типов | Нет |

### Выполнение (Execution)

| Инструмент | Описание | Требует подтверждения |
|------------|----------|:---------------------:|
| `Bash` | Выполнение команд оболочки в окружении | Да |
| `PowerShell` | Нативное выполнение команд PowerShell (в Windows) | Да |
| `Monitor` | Фоновое отслеживание команды/логов с потоковой передачей вывода в Claude | Да |

### Сеть и Web

| Инструмент | Описание | Требует подтверждения |
|------------|----------|:---------------------:|
| `WebSearch` | Поиск в интернете с возвратом заголовков и URL | Да |
| `WebFetch` | Загрузка веб-страницы с конвертацией HTML в Markdown и извлечением ответа | Да |

### Агенты и оркестрация

| Инструмент | Описание | Требует подтверждения |
|------------|----------|:---------------------:|
| `Agent` | Запуск субагента в собственном изолированном контекстном окне | Нет |
| `Workflow` | Запуск динамического сценария на JavaScript, оркестрирующего множество субагентов | Да |
| `ListAgents` | Список доступных сессий (субагенты, коллеги по команде, другие локальные сессии) | Нет |
| `SendMessage` | Отправка сообщения субагенту, участнику команды или другой сессии | Нет |

### Управление задачами (Tasks API)

*На моделях Opus 5.5 и Sonnet 5.5 включается через `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`.*

| Инструмент | Описание | Требует подтверждения |
|------------|----------|:---------------------:|
| `TaskCreate` | Создать задачу в персистентном списке сессии | Нет |
| `TaskGet` | Получить полные детали конкретной задачи | Нет |
| `TaskList` | Список всех задач с их текущими статусами | Нет |
| `TaskUpdate` | Обновить статус задачи, зависимости или удалить ее | Нет |
| `TaskStop` | Принудительно завершить фоновую задачу по ID | Нет |

### Планирование и автоматизация (Scheduling)

| Инструмент | Описание | Требует подтверждения |
|------------|----------|:---------------------:|
| `CronCreate` | Запланировать периодический или отложенный запуск промпта в сессии | Нет |
| `CronDelete` | Отменить запланированную задачу по ID | Нет |
| `CronList` | Список активных запланированных задач сессии | Нет |
| `ScheduleWakeup` | Внутреннее планирование следующего шага цикла `/loop` | Нет |
| `RemoteTrigger` | Управление облачными сценариями (Routines) на claude.ai | Нет |
| `PushNotification` | Отправка десктопных и мобильных push-уведомлений | Нет |

## Форматы правил разрешений (Permission Rules)

Имена инструментов задаются в файлах конфигурации с опциональным спецификатором:

| Формат правила | К чему применяется | Что фильтрует |
|----------------|---------------------|---------------|
| `Bash(npm run *)` | `Bash`, `Monitor` | Команды шелла по префиксу / glob |
| `PowerShell(Get-* *)` | `PowerShell` | Команды PowerShell |
| `Read(~/secrets/**)` | `Read`, `Grep`, `Glob`, `LSP` | Пути к файлам |
| `Edit(/src/**)` | `Edit`, `Write`, `NotebookEdit` | Пути к файлам |
| `Skill(deploy *)` | `Skill` | Префикс имени навыка |
| `Agent(Explore)` | `Agent` | Тип субагента |
| `WebFetch(domain:example.com)` | `WebFetch` | Доменное имя |
| `WebSearch` | `WebSearch` | Разрешение/запрет инструмента целиком |

> Правило `Edit(...)` автоматически разрешает и чтение указанного пути (`Read(...)`).

## Особенности поведения инструментов

### Bash
- Каждая команда запускается в отдельном дочернем процессе. Переходы через `cd` сохраняются в рамках основной сессии, но переменные, установленные через `export`, между командами не сохраняются.
- Таймаут по умолчанию: 2 минуты (до 10 минут по запросу модели).
- Вывод по умолчанию ограничен 30 000 символов (настраивается параметром `BASH_MAX_OUTPUT_LENGTH`). При превышении полный вывод сохраняется во временный файл, а модель получает путь к нему.

### Edit
- Выполняет точную замену подстроки. `old_string` должна совпадать посимвольно (включая все пробелы и переносы) и встречаться в файле ровно один раз.
- Файл должен быть предварительно прочитан моделью в текущей сессии перед редактированием.

### Glob и Grep
- `Glob` ищет файлы по шаблону (до 100 результатов, сортировка по времени изменения). По умолчанию не учитывает `.gitignore`.
- `Grep` использует быстрый движок ripgrep, соблюдает `.gitignore` и выводит номера строк.

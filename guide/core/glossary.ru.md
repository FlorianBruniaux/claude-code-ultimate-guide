# Глоссарий по Claude Code

Определения ключевых терминов, используемых в данном руководстве. Для общих понятий уровня модели (токены, температура, RAG) обратитесь к официальному глоссарию платформы Anthropic.

---

## A

### Agent teams (Команды агентов)
Несколько независимых сессий Claude Code, координируемых ведущим агентом (team lead), с общим списком задач и прямым обменом сообщениями (peer-to-peer). В отличие от субагентов (работающих внутри одной сессии), каждый участник команды имеет собственное контекстное окно.

### Agentic loop (Агентный цикл)
Цикл, через который Claude проходит при решении задачи: сбор контекста → выполнение действия → проверка результата → повторение до завершения. Результат каждого вызова инструмента определяет следующий шаг.

### Auto memory (Авто-память)
Заметки, которые Claude автоматически сохраняет для себя на основе ваших правок и предпочтений. Хранятся для каждого репозитория в `~/.claude/projects/`. Первые 200 строк или 25 КБ файла `MEMORY.md` загружаются на старте сессии.

### Auto mode (Авто-режим)
Режим разрешений, в котором отдельная модель-классификатор в фоне проверяет каждое действие вместо показа диалогов подтверждения. Блокирует эскалацию прав, недоверенную инфраструктуру и попытки prompt injection.

---

## B

### Bare mode (Чистый режим)
Флаг запуска (`--bare`), отключающий автоматическое обнаружение хуков, навыков, плагинов, MCP-серверов, авто-памяти и CLAUDE.md. Рекомендуется для CI/CD и скриптов, где требуется идентичное поведение на разных машинах.

### Bundled skills (Встроенные навыки)
Пакетные сценарии, поставляемые с Claude Code: `/batch`, `/code-review`, `/debug`, `/loop`. В отличие от жестко закодированных команд, они передают модели детальный промпт и позволяют ей самостоятельно оркестрировать шаги.

---

## C

### Channel (Канал)
MCP-сервер, передающий внешние события в вашу активную сессию, позволяя Claude реагировать на события, пока вас нет за терминалом (двусторонние интеграции с Telegram, Discord и др.).

### Checkpoint (Контрольная точка)
Точка восстановления, создаваемая перед каждым вашим запросом. Claude Code делает снимок файлов перед каждым редактированием, позволяя откатить код (`/rewind` или двойное нажатие `Esc`).

### CLAUDE.md
Markdown-файл постоянных инструкций для Claude, загружаемый на старте каждой сессии. Здесь фиксируются соглашения по коду, архитектура, команды запуска тестов и правила взаимодействия.

### Compaction (Сжатие контекста)
Автоматическое или ручное (`/compact`) резюмирование диалога при приближении контекстного окна к лимиту токенов для освобождения оперативной памяти сессии.

---

## E

### Effort level (Уровень усилий)
Параметр (`/effort`), управляющий тем, какую часть бюджета адаптивных рассуждений (thinking tokens) Claude использует на каждом шаге. Более высокий уровень обеспечивает глубокий анализ, более низкий — экономит время и токены.

---

## H

### Agent harness (Обвязка / харнесс агента)
Среда выполнения (рантайм) вокруг модели: собирает контекст, предоставляет инструменты, применяет правила разрешений, сохраняет состояние и возвращает вывод инструментов обратно в модель. Claude Code является примером runtime harness, а Claude — моделью, которую он запускает.

### Hook (Хук)
Скрипт или программа, автоматически вызываемая в определенные моменты жизненного цикла Claude Code (до выполнения инструмента, после редактирования файла, при старте сессии). Хуки детерминированы и не зависят от усмотрения модели.

---

## M

### MCP (Model Context Protocol)
Открытый протокол подключения ИИ-ассистентов к внешним сервисам, базам данных, браузерам и API через стандартизированный клиент-серверный интерфейс.

---

## P

### Permission mode (Режим разрешений)
Базовый уровень доверия сессии: `default` (запрашивает подтверждение перед действиями), `acceptEdits` (авто-принятие правок файлов), `plan` (только чтение и планирование), `auto` (классификатор безопасности) и `bypassPermissions` (без подтверждений, только для CI/CD).

### Plan mode (Режим планирования)
Безопасный режим работы (`/plan`), в котором модель исследует кодовую базу, читает файлы и формирует план, не внося никаких изменений до вашего одобрения.

---

## S

### Subagent (Субагент)
Специализированный ИИ-помощник, запускаемый в собственном изолированном контекстном окне с отдельным системным промптом и ограниченным набором инструментов. Выполняет подзадачу и возвращает краткий итог в основной диалог.

---

## T

### Tool (Инструмент)
Действие, доступное Claude: чтение файла (`Read`), редактирование (`Edit`), выполнение команды шелла (`Bash`), поиск по коду (`Grep`, `Glob`) или вызов субагента. Именно инструменты делают модель агентной.

### Turn (Шаг / ход)
Один полный цикл ответа Claude внутри сессии: начинается с отправки сообщения пользователем и заканчивается завершением генерации ответа моделью.
